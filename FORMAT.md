# Расширенный формат источников

## 1. Общие правила и грамматика

Файл — JSON в UTF-8. Корневой объект описывает один источник. Никакой конвертации старых файлов не требуется: отсутствие `type` означает `periodic`. Все три типа поддерживаются в `generate` и `prob`.

```text
Description = Periodic | Markov | Mixture
Periodic    = {"type"?: "periodic", "models": Models,
               "switches": Switches, "source": [SwitchName, ...]}
Markov      = {"type": "markov", "depth": PositiveInteger,
               "alphabet": [Symbol, ...], "initial": ContextDistribution,
               "transitions": {Context: SymbolDistribution, ...}}
Mixture     = {"type": "mixture", "components": [Component, ...]}
Component   = {"weight": Probability, "source": Description}
Distribution = {Name: Probability, ...}
```

В этой записи `?` означает необязательное поле, а `...` — продолжение списка или объекта, не буквальный JSON. Обязательные поля проверяются; дополнительные поля игнорируются. Пустые распределения, модели, переключатели, список `source`, алфавит и список компонентов не допускаются. Имена в JSON — строки. Ссылки на неизвестные модели, переключатели, контексты и символы отклоняются.

Вероятности задаются строками: например, `"1/3"`, `"0.25"`, `"0"`. Они разбираются `Fraction`; JSON-числа вместо строк не принимаются. Вероятности неотрицательны, сумма каждого распределения и сумма весов компонентов должны быть точно равны единице. Нулевые вероятности допустимы, отсутствующие элементы распределения означают ноль. Диагностика некорректного входа направляется в stderr, код завершения — 2.

## 2. Семантика источников

**Periodic.** `models` сопоставляет имени модели распределение символов. `switches` сопоставляет имени переключателя распределение имён моделей. На первом такте используется `source[0]`, затем список обходится циклически. На каждом такте независимо выбираются модель и символ. Реализация заранее сворачивает переключатель в распределение символов по формуле полной вероятности. Это сохраняет закон источника. Алфавит — объединение символов всех моделей, длина периода описания `L = len(source)`.

**Markov.** `depth = d > 0` — число предыдущих символов, определяющих распределение следующего. Символы алфавита — различные непустые строки без пробельных символов. Контекст записывается строкой из ровно d символов алфавита, разделённых одиночными обычными пробелами. Например, для d=2: `"a b"`. `initial` задаёт совместное распределение первых d символов. Сначала выбирается и выдаётся этот контекст, затем следующий символ выбирается по `transitions[context]`; контекст сдвигается на один символ. При N<d выдаются только первые N символов. Таблица переходов содержит все k^d контекстов, даже недостижимые. Стационарность не навязывается: она зависит от `initial` и переходов.

Пример марковского источника варианта s=3:

```json
{
  "type": "markov", "depth": 1,
  "alphabet": ["a", "b", "c", "d", "e"],
  "initial": {"a": "1"},
  "transitions": {
    "a": {"b": "1"}, "b": {"c": "1"}, "c": {"d": "1"},
    "d": {"e": "1"}, "e": {"a": "1"}
  }
}
```

**Mixture.** Компонент выбирается по `weight` ровно один раз на всю реализацию. Все следующие символы выдаёт выбранный источник. Компоненты могут быть любыми описаниями, включая вложенные смеси. Алфавит — объединение их алфавитов. Вероятность блока — сумма вероятностей по компонентам с их весами; если символ отсутствует в алфавите компонента, его вклад равен нулю. Смешивание стационарных компонентов сохраняет стационарность, но может нарушить эргодичность. Сам по себе тип `mixture` не гарантирует ни стационарности, ни неэргодичности.

## 3. Величины в режиме prob

Первая величина — точная вероятность блока с позиции 1. Третья — число совпадений среди всех перекрывающихся окон реализации, делённое на N-r+1. Требуется 1≤r≤N. Таблица для N=100, 1000, 10000, 100000, 1000000 строится по префиксам одной реализации; строки с N<r пропускаются с пояснением.

В исходном формате вторая величина — точное среднее вероятности блока по L позициям периода. Для расширения принято проектное решение: выводить предел средних вероятностей по первым T начальным позициям при T→∞, название в CLI — `long-run average`. Для периодического источника он совпадает с требуемым средним по периоду; для стационарного — с первой величиной. PDF не задаёт это обобщение явно.

Для конечного Markov предел существует и вычисляется точно: находятся замкнутые классы цепи контекстов, инвариантное распределение каждого класса и вероятность попадания в него из `initial`. Решаются системы с рациональными коэффициентами. Для смеси ответ усредняется по компонентам. Это среднее вероятностей по модели, а не обещание предела частоты каждой отдельной реализации: у неэргодической смеси такие пределы могут различаться.
