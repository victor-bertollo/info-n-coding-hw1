## Точные расчёты и сложность

Вероятность периодического блока — произведение распределений соответствующих позиций. Для Markov суммируются вероятности допустимых начальных контекстов и последующих переходов. Если блок начинается внутри первых d символов, сначала проверяется совпадение с этой частью контекста. Полный перебор коротких реализаций в тестах независимо проверяет этот переход через границу начального контекста.

Для предельного среднего строится конечная цепь контекстов. В каждом замкнутом классе решаются уравнения πP=π и sum(π)=1. Для переходных состояний вероятность попадания в заданный класс удовлетворяет (I-Q)h=b, где b — вероятность перейти в класс за один шаг. Затем учитывается исходное распределение: вес класса равен его начальной массе плюс взвешенные вероятности попадания из переходных состояний. Смесь инвариантных распределений задаёт среднее распределение контекста; по нему вычисляется вероятность блока. Метод применим и к периодическим цепям: сходимость отдельных распределений по времени не требуется.

Пусть S=k^d, E≤Sk — число рёбер, C — число замкнутых классов, T — число переходных состояний. Нынешняя реализация достижимости из каждого состояния требует O(S(S+E)) операций и до O(S²) памяти. Метод Гаусса для системы размера n требует O(n³) рациональных операций и O(n²) памяти. Системы поглощения решаются отдельно для классов: O(C·T³); системы внутри классов — сумма кубов их размеров. Стоимость больших целых чисел здесь не считается постоянной. Это учебная реализация для малых S, не оптимизированная для больших глубин. Подсчёт окон использует O(r) памяти; сравнение каждого окна стоит O(r).
