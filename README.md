# Домашняя работа №1: теория информации и кодирования

Вариант **s=3**. Реализована задача 1.1: периодические источники, источники Маркова и смеси. Задачи 1.2 и 1.3 пока не реализованы.

Нужен **Python 3.13 или новее** (проверено на Python 3.14.9); внешних библиотек нет. Все команды ниже выполняются из каталога `hw1`. Скрипт запуска — `src/main.py`.

```bash
python src/main.py --variant
python src/main.py task11 generate tests/task11/variant.json 100 --seed 3
python src/main.py task11 prob tests/task11/variant.json 1000 c a e --seed 3
python src/main.py task11 prob tests/task11/markov.json 1000 a b --seed 3
python src/main.py task11 prob tests/task11/mixture.json 1000 a --seed 0
```

Если используется uv, замените `python` на `uv run python`. Для справки: `python src/main.py task11 --help` и `python src/main.py task11 prob --help`.

`generate` при N>0 выдаёт N символов; при `None`, нуле или отрицательном N работает до **Ctrl+C** (код 130). Для вывода в файл используйте перенаправление `> output.txt`. При буферизации вывод может появляться порциями; для немедленного вывода можно запустить `python -u`.

```bash
python src/main.py task11 generate tests/task11/variant.json None --seed 3
```

Если каждый символ алфавита состоит из одного знака, результат выдаётся без разделителей, блок можно передать как `ab` или `a b`. Иначе символы блока передаются отдельными аргументами, а генерация разделяет их пробелами. Для старого формата с пробелами внутри символов текстовый вывод не является однозначной сериализацией; вычисления работают с исходными строковыми символами.

`prob` выводит две точные рациональные величины, частоту и таблицу для длин до миллиона. Поэтому даже при N=100 генератор обрабатывает миллион символов. Одинаковые вход и seed дают одинаковый результат в проверенной среде. Ошибки входа печатаются в stderr с кодом 2.
